# Публикация сайта (постоянная ссылка)

Сайт написан на Flask. Чтобы девушка могла открыть его по ссылке из любого места,
его нужно выложить на хостинг. Ниже — самый простой бесплатный способ: **Render**.

Понадобятся два бесплатных аккаунта:

1. **GitHub** — там будет храниться код сайта.
2. **Render** — он соберёт сайт из GitHub и выдаст ссылку.

---

## Шаг 1. GitHub

1. Зарегистрируйся на <https://github.com> (если ещё нет аккаунта).
2. В терминале авторизуй GitHub CLI:

   ```bash
   gh auth login
   ```

   Выбери: GitHub.com → HTTPS → Login with a web browser → скопируй код и вставь в браузере.

3. Создать репозиторий и отправить туда код:

   ```bash
   gh repo create my-universe --public --source=. --push
   ```

## Шаг 2. Render

1. Зарегистрируйся на <https://render.com> — удобнее всего через кнопку **GitHub**
   (тогда Render сразу получит доступ к репозиторию).
2. Нажми **New +** → **Web Service**.
3. Выбери репозиторий `my-universe`.
4. Проверь настройки (обычно подставляются сами):

   - **Runtime:** Python
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `gunicorn app:app --bind 0.0.0.0:$PORT`
   - **Plan:** Free

5. Нажми **Create Web Service** и подожди пару минут.
6. Готово — сверху появится ссылка вида `https://my-universe.onrender.com`.

---

## Важные моменты

- **Холодный старт.** На бесплатном тарифе Render «усыпляет» сайт после простоя.
  Первое открытие после паузы может занять 30–60 секунд, дальше — быстро.
- **Обновление текстов.** После правок в `content.py` нужно снова отправить код
  на GitHub, и Render пересоберёт сайт:

  ```bash
  git add -A
  git commit -m "Обновил тексты"
  git push
  ```

- **Локальный запуск** для проверки правок остаётся прежним: `python app.py`.

## Альтернативы Render

- **PythonAnywhere** — можно загрузить файлы прямо через браузер, без GitHub.
- **Railway**, **Vercel**, **Fly.io** — тоже подойдут, но настройка чуть сложнее.
