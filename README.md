# Моя маленькая вселенная 🌌

Небольшой романтический сайт на Python + Flask. Космос, открытка-сердечко,
интерактивные звёзды и мини-игра нарисованы кодом — внешние картинки не нужны.

## 1. Что понадобится

- Python 3.10 или новее
- VS Code (или любой редактор)
- Интернет нужен только для публикации сайта; локально проект работает без него.

## 2. Установка

Открой терминал в папке проекта и выполни:

```bash
python -m venv .venv
```

Активируй окружение.

**Windows:**
```bash
.venv\Scripts\activate
```

**macOS / Linux:**
```bash
source .venv/bin/activate
```

Установи зависимости:

```bash
python -m pip install -r requirements.txt
```

## 3. Запуск

```bash
python app.py
```

Открой в браузере адрес, который появится в терминале. Обычно это:

`http://127.0.0.1:5000`

Остановка сервера: `Ctrl+C` в терминале.

## 4. Где что менять

- `content.py` — **все тексты сайта**: письмо, послания на звёздах, игра, финал.
- `templates/index.html` — структура страницы (обычно трогать не нужно).
- `static/css/style.css` — цвета, размеры, эффекты и внешний вид.
- `static/js/script.js` — звёздное небо, интерактивные звёзды и мини-игра.
- `app.py` — Python/Flask, страницы и маршруты.

## 5. Как написать своё письмо и послания

Открой `content.py` — там понятные поля с комментариями.

- Своё письмо пиши в переменной `LETTER_TEXT` (между `""" ... """`).
- Обращение — в `LETTER_GREETING`, подпись — в `LETTER_SIGNATURE`.
- Послания на звёздах — это список `GALAXY_STARS` (у каждой: `label`, `title`, `message`).
- Послания за победу в игре — список `GAME_WIN_MESSAGES` (показываются по очереди,
  после каждой победы — следующее; когда список закончится, начинается заново).
- Сколько звёзд собирать и время игры — `GAME_TARGET` и `GAME_DURATION`.

После сохранения файла просто обнови страницу в браузере — изменения подхватятся сами.
В игре есть счётчик «Сыграно»: он покажет, сколько раз она играла (хранится в браузере).

## 6. Как поделиться сайтом

Локальный адрес `127.0.0.1` виден только на твоём компьютере.
Чтобы девушка могла открыть сайт по ссылке из другого места, нужно
опубликовать проект на хостинге, который поддерживает Python/Flask.
Перед публикацией выключи `debug=True` в `app.py`.

## Примечания

- Сайт адаптирован под телефон и компьютер.
- Музыка не запускается сама: браузеры обычно блокируют автозапуск звука.
  Кнопка звука включает короткие синтезированные звуковые сигналы.
- Все иллюстрации и эффекты создаются кодом; AI-картинки не используются.
